# Idea backlog

Park ideas here before Saturday. When the tracks drop, we bend the closest one to fit rather than
starting from a blank page.

Use this shape for each idea:

```
### <name>

- **Who hurts:** the specific person/role with the problem
- **The pain:** what it costs them today (time, money, error rate)
- **What we build:** the thing, in one sentence
- **The demo:** what a judge sees on screen in 3 minutes
- **Hard part:** the bit that could sink us
- **Fakeable:** what we can mock without lying about it
```

---

### (example — replace)

- **Who hurts:** ops manager at a 40-person services firm
- **The pain:** 6 hours a week reconciling supplier invoices against quotes by hand
- **What we build:** an agent that reads both, flags the discrepancies, and drafts the supplier email
- **The demo:** drop in a messy PDF pair, watch it flag a real overcharge, review the draft, send
- **Hard part:** PDF extraction on bad scans
- **Fakeable:** the email actually sending — show the draft, don't wire up SMTP
