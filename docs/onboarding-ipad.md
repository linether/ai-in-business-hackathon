# 在 iPad 上参加这个黑客松

给 Lillian（@lillianguo1031-cyber），或者任何没有电脑可用的人。

**结论先说：iPad 完全够用，而且你能负责的部分是评分表里最值钱、大多数队伍最不重视的那一块。**
不要因为没有笔记本就觉得自己只能打杂。

## 第一步：2 分钟，什么都不用装

现在就能做完，不需要 git、不需要终端、不需要任何安装。

1. **接受邀请**（Safari 里登录 GitHub 后打开）
   https://github.com/linether/ai-in-business-hackathon/invitations

2. **打开留言板**
   https://github.com/linether/ai-in-business-hackathon/blob/main/BOARD.md

3. 点右上角的**铅笔图标 ✏️**

4. 拉到文件最底部，照着 `CHECKIN` 那条里的模板，追加你的签到

5. 点绿色的 **Commit changes** → 再点一次确认

**就这样。** 这样提交的 commit 会自动归属到你的 GitHub 账号，
连 `git config user.email` 那个最容易出错的坑都一起绕过去了。

> 主办方会审查提交历史，每个人的 commit 必须显示成自己。网页编辑天然满足这一点。

## 在 iPad 上干活的三种方式

按「上手成本」排序，从低到高。**大多数时候第一种就够了。**

### 方式一：GitHub 网页版（零安装，推荐日常使用）

Safari 里直接用 github.com 就能：读所有文件、编辑、提交、建分支、开 PR、评论、审阅。

写文档、改 README、填评测标注、参与讨论——**全部够用**。

小技巧：在任意仓库页面，把网址里的 `github.com` 改成 **`github.dev`**，
会打开一个浏览器版的 VS Code，可以同时编辑多个文件。iPad 上配个蓝牙键盘会舒服很多。

### 方式二：GitHub Codespaces（有真正的终端）

如果你确实需要跑命令、跑 Python、装依赖：

1. 仓库首页 → 绿色 **Code** 按钮 → **Codespaces** 标签 → **Create codespace on main**
2. 等一两分钟，Safari 里会开出一个完整的 VS Code，**带终端**
3. 里面 git、Python、Node 都是现成的，什么都不用装

这等于借了一台云端 Linux 电脑，用 iPad 当屏幕。

注意：
- 个人账号有**每月免费额度**，够用一个周末，但**不用的时候记得手动 Stop**，否则会持续消耗
- 强烈建议配蓝牙键盘，纯触屏写代码很痛苦
- 具体剩余额度在 https://github.com/settings/billing 能看到

### 方式三：Working Copy（原生 App，可选）

App Store 上的 iPad git 客户端，体验相当好。免费版可以 clone 和浏览，
**推送需要付费解锁**（一次性，约 $20）。

我们这个周末**不需要**它——网页版和 Codespaces 足够了。不用花这个钱。

## iPad 上做不了的事

诚实地列出来，这样分工时不会踩空：

- ❌ 在本地跑我们的应用 / 起 dev server
- ❌ Docker
- ❌ 在本地跑命令行 AI 工具（但 **Codespaces 的终端里可以**）

所以**「在本地调试后端」这类活不要分给 iPad**。其他绝大部分都能干。

## 你应该负责什么（这不是安慰）

看一眼评分表 [judging.md](judging.md)：100 分里，有一大块**根本不是写代码挣的**。

| 你能做的 | 值多少分 | 为什么适合 iPad |
| --- | --- | --- |
| **商业价值论证**：谁在痛、今天花多少钱、用了我们的方案花多少钱 | **25 分**（问题重要性 8 + 可行性 8 + 影响 9） | 这是调研和算账，不是编程 |
| **市场验证电话**：以家长身份打几家补习机构，记录响应时间 | 直接支撑上面那 25 分 | 这活本来就该用电话打 |
| **3–5 分钟 demo 视频** | 初赛 80 分**全部**由这个视频评定 | iPad 剪视频比电脑还顺手（iMovie / CapCut） |
| **Pitch 演示文稿** | 决赛 20 分的载体 | Keynote 在 iPad 上很好用 |
| **README 与文档** | 6 分（代码质量那项靠文档拿） | 网页版直接编辑 |
| **评测数据标注**：听 20–30 段通话，标「该不该转人工」 | 6 分（数据与模型），几乎没队伍做 | 戴耳机听就行 |
| **录制语音样本**：不同情绪的模拟通话 | 我们的评测集需要真人录音 | iPad 麦克风够用 |

**说白了：初赛 80 分是靠一段视频评出来的，而视频是你的活。**
写代码的人做出来的东西，最后能不能拿分，取决于那 5 分钟拍得好不好。
