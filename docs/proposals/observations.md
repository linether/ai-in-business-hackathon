# 观察池

**没有点子也能交。这里收的不是方案，是你亲眼见过的事。**

一份好点子很难在两小时里想出来。但每个人都能回答：**你见过谁在重复做什么又烦又蠢的事？**
四个人的观察凑在一起，比四个人各自憋出来的点子有用得多。

赞助商（也是评委）的原话：先选你懂的行业，再选技术；去找那些枯燥重复的活；
去人迹罕至的地方。**这个文件就是我们的"人迹罕至的地方"。**

## 怎么交

直接在这个文件末尾追加，格式随意。github.com 上点铅笔图标 ✏️ 编辑即可，
iPad 也能做。这个文件设了 union 合并，多人同时写不会冲突。

一条观察写三行就够：

```
- @你的handle｜在哪见到的（兼职/家里生意/实习/社团/学校）
  谁在做这件事，具体做什么
  为什么烦：多久一次、一次多长时间、做错了会怎样
```

## 想不起来？照着这几个问题问自己

- 我打工的时候，**哪件事本来就该让电脑做**，但一直是我手动做的？
- 我家/我朋友家的生意，**哪些环节还在用纸、微信、Excel 手工转**？
- 我管的那个社团，**同一个问题被问过多少遍**？
- 有人**花钱请我做过什么无聊到麻木的事**？
- 哪里**因为没人有空去看，钱就悄悄漏掉了**？
- 我认识的人里，谁**每周固定花半天做一件重复的事**？

越具体越好。「排课很麻烦」没用；
「行政老师每周三花四小时手工核对 200 个学生的课时余额，错了家长会投诉」——这个能做。

## 不用管这些

- 不用想 AI 怎么解决，那是后面的事
- 不用管做不做得完
- 不用管是不是"够有商业价值"
- **重复、琐碎、不起眼，正是我们要找的**
